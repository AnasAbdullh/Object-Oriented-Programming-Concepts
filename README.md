# Object-Oriented Programming (OOP) Concepts in C++

This repository provides a comprehensive collection of examples and projects focused on mastering **Object-Oriented Programming (OOP)** principles using **C++**. It includes code snippets, exercises, and projects that cover various OOP concepts, from the basics to more advanced topics.

## Key Features:
- **Foundational Concepts**:
  - Classes and Objects.
  - Constructors and Destructors (including Parameterized and Copy Constructors).
  - Access Specifiers and Modifiers.
  - Friend Functions and Friend Classes.
  - Static Members and `this` Pointer.

- **Advanced Topics**:
  - Inheritance (including Upcasting and Downcasting).
  - Function Overloading and Virtual Functions.
  - Static (Early Binding) vs. Dynamic (Late Binding).
  - Properties: Setters, Getters, and Read-Only Properties.

- **Project Highlights**:
  - **Date Library Project**: A reusable library for handling date-related operations in C++.
  - **String Library Project**: Solutions for string manipulation using classes and objects.
  - **Calculator Project**: A practical exercise to implement a calculator with OOP concepts.

- **Practical Exercises**:
  - Passing objects to functions by reference and value.
  - Adding objects to vectors and dynamic arrays.
  - Structures inside classes.

## Getting Started:
1. Clone the repository:
   ```bash
   git clone https://github.com/AnasAbdullh/Object-Oriented-Programming-Concepts.git

2. Navigate to the project folder:

cd Object-Oriented-Programming-Concepts


3. Compile and run the C++ files:

g++ ClassesAndObjects.cpp -o ClassesAndObjects
./ClassesAndObjects



Learning Benefits:

This repository is designed for students and developers who want to:

Understand and apply OOP principles in real-world scenarios.

Learn through clear and well-structured examples.

Develop reusable and modular code using C++.

# مفاهيم البرمجة الكائنية (OOP) باستخدام C++

يقدم هذا المستودع مجموعة شاملة من الأمثلة والمشاريع التي تركز على إتقان **مفاهيم البرمجة الكائنية (OOP)** باستخدام **C++**. يحتوي على مقاطع برمجية، تمارين، ومشاريع تغطي مفاهيم OOP من الأساسيات إلى المواضيع المتقدمة.

## الميزات الرئيسية:
- **المفاهيم الأساسية**:
  - الكلاسات والكائنات.
  - المنشئون والمدمرون (بما في ذلك المنشئون المخصصون ونسخ المنشئين).
  - محددات الوصول.
  - دوال وأصناف الأصدقاء.
  - الأعضاء الثابتون ومؤشر `this`.

- **المواضيع المتقدمة**:
  - الوراثة (بما في ذلك Upcasting وDowncasting).
  - التحميل الزائد للدوال والدوال الافتراضية.
  - الربط الثابت (المبكر) مقابل الربط الديناميكي (المتأخر).
  - الخصائص: الإعداد، الحصول، والخصائص للقراءة فقط.

- **أهم المشاريع**:
  - **مشروع مكتبة التاريخ**: مكتبة قابلة لإعادة الاستخدام للتعامل مع العمليات المتعلقة بالتواريخ في C++.
  - **مشروع مكتبة النصوص**: حلول لمعالجة النصوص باستخدام الكلاسات والكائنات.
  - **مشروع الآلة الحاسبة**: تمرين عملي لتنفيذ آلة حاسبة بمفاهيم البرمجة الكائنية.

- **تمارين عملية**:
  - تمرير الكائنات إلى الدوال بالقيمة والمرجع.
  - إضافة الكائنات إلى المصفوفات الديناميكية و`vectors`.
  - الهيكل داخل الكلاسات.
